# 🛡️ GhostResearcher: Autonomous Industry Analyst

**GhostResearcher** is an agentic AI tool designed to automate deep industry research. Built with **Groq** for high-speed inference and **Tavily** for real-time web intelligence, it transforms 4 hours of manual Googling into a structured 30-second briefing.

## 🚀 Features
- **Autonomous Web Browsing:** Uses Tavily's AI-native search to find high-signal industry data.
- **Sub-second Reasoning:** Powered by Llama 3 via Groq LPU for near-instant report generation.
- **Deep Synthesis:** Not just a summarizer—it identifies a "Unique Angle" for strategic insight.
- **Exportable Reports:** One-click download of research as professional Markdown files.

## 🛠️ Tech Stack
- **Brain:** Groq (Llama-3.3-70b-versatile)
- **Search:** Tavily API
- **UI:** Streamlit
- **Environment:** Python 3.10+, VS Code
